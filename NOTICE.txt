sqlite 3.46.1 for tOS
=====================

Built from the release tarball beside this package (sqlite-autoconf-3460100.tar.gz), unmodified, with prefix /system/pkg/sqlite: headers in include/, libraries in lib/. gcc finds them by itself (its specs list this folder). License: Public domain (LICENSE).
glibc: its programs and shared libraries are linked dynamically against the GNU C Library, which tOS's base system carries in /lib64 and /lib/x86_64-linux-gnu.
